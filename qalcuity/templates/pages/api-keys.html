Cara Menggunakan API Key

Sertakan header berikut di setiap request API:

X-Qalcuity-Key:
X-Qalcuity-Secret:

Contoh request dengan curl:

curl -X GET https://qalcuity.com/api/v1/profile \
  -H "X-Qalcuity-Key: qk_abc123..." \
  -H "X-Qalcuity-Secret: your_secret_here"

Permissions: Read Only — Hanya bisa membaca data.
Read & Write — Bisa membaca dan mengubah data.
